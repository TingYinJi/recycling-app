### 基於深度學習之智慧回收分類助手 (Deep Learning-Based Smart Waste Sorting System) ###

本專案為實作具備即時物件檢測與分類能力的智慧資源回收輔助應用程式，旨在透過邊緣運算（Edge AI）解決大眾在日常生活面對繁雜垃圾分類時的痛點。

## 💡 專案背景與動機 (Motivation)
- **民眾辨識困難**：大眾普遍對資源回收分類不熟悉，複雜的標示常導致錯誤分類。
- **時間成本過高**：手動查詢政府回收手冊或網站耗時費力，降低民眾參與意願。
- **汙染風險與效率低落**：錯誤分類會增加後端處理負擔，傳統人工分類效率不彰。

## 🛠️ 技術架構與模型實作 (Technical Implementation)
- **模型選擇**：採用 **YOLOv8**，在行動裝置上兼顧高 FPS（即時性）與低計算成本。
- **資料集與前處理**：
  - 自行收集在地化包裝與回收物影像。
  - 透過 Roboflow 進行 3 倍資料擴增（包含水平/垂直翻轉、隨機旋轉 $\pm 15^\circ$、裁切縮放）。
- **邊緣運算部署**：將模型轉換並優化以適應行動端，實現低延遲的即時辨識。

## 📊 模型評估與效能 (Evaluation)
- **準確率表現**：模型之 mAP50-95 達到 **82.2%**。
- **推論速度**：確保單次檢測延遲控制在 **<100ms** 內，提供流暢的行動端體驗。

## 📱 App 介面與互動設計 (App Interface & UX)
- **即時匡選 (Real-time Bounding Boxes)**：在觀景窗中即時標記並框選多個回收物目標。
- **智慧回饋 (Smart Feedback)**：即時顯示分類指引（如「請投【玻璃容器類】(小心易碎)」、「請投【鐵鋁罐/金屬類】」等）。

## 🚀 未來展望 (Future Work)
- **擴充有害垃圾資料集**：納入更多複雜品項以提升模型泛化能力。
- **優化 App UI/UX**：根據使用者回饋持續精進介面互動。
- **實作智慧分類回收桶**：結合硬體設備開發自動化分類回收箱，降低後端處理成本。
